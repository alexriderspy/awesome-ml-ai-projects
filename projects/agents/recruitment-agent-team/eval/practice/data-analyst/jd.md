# Data Analyst, Customer Insights

Panel: analytics

Brindle Box is a meal-kit subscription company. The insights team answers "why did this metric move?" for
marketing, product and operations.

## Must have
- Advanced SQL (multi-table joins, window functions) on a production data warehouse
- Building dashboards in Tableau, Looker, Power BI or a similar tool that business teams use
- Designing or analysing A/B tests or other experiments with basic statistics
- Presenting findings and recommendations to non-technical audiences

## Nice to have
- Python or R for analysis
- dbt or other data modelling work
- Subscription or e-commerce experience
