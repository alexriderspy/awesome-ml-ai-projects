# Backend Engineer, Payments API

Panel: backend

Tallyfold is a small fintech that moves money between marketplaces and their sellers. You will build and run
the services behind our public Payments API.

## Must have
- 3+ years building production backend services in Python or Go
- Designing relational database schemas (PostgreSQL or MySQL) and tuning slow queries
- Building and versioning REST or gRPC APIs used by other teams or customers
- Writing automated tests and shipping through a CI pipeline

## Nice to have
- Payments, billing or ledger systems
- Kubernetes or another container orchestrator
- Taking part in an on-call rotation and running incident reviews
